# 产品功能基线与迭代验收

后续版本在升级数据源时必须保留以下能力；此文件和自动检查共同作为回归依据。

| 能力             | 必须保持的行为                                                  | 验证位置                                            |
| ---------------- | --------------------------------------------------------------- | --------------------------------------------------- |
| 个人档案         | 学历、专业、经历、技能等保存在本机，公开索引不包含简历          | 手机/电脑 UI 回归；构建只复制 public 和指定前端模块 |
| 求职偏好         | 内地/香港、城市、岗位、薪资、工作方式、排除词继续生效           | match、brief、search 单元测试及 UI 回归             |
| 匹配分析         | 0–100 分、证据、差距与建议；信息不足不评分；年龄性别不参与      | match、details 单元测试                             |
| 机会与投递计划   | 查看正文、收藏、投递状态、刷新后保留                            | 手机/电脑 UI 回归                                   |
| 每日简报         | 仅应用内；后台每天北京时间 08:00 计划更新，可能延迟             | daily workflow；brief 单元测试                      |
| 最新搜索与历史池 | 按方向/地区检索、分页、每日额度、有效历史保留和过期过滤         | coverage、search、history 单元测试                  |
| 手机与电脑       | 响应式网站、安装 PWA、相对路径适配 GitHub Pages                 | 390/1440 像素浏览器回归；manifest/SW 构建检查       |
| 数据真实性       | 官网入口不等于接通 API；验证页、403/405、汇总页不能冒充具体岗位 | details、pipeline、iteration 单元测试               |
| 本机正文导入     | 复用现有评分，显示用户提供；不上传、不冒充自动核验；可删除      | iteration 单元测试与浏览器回归                      |

## 本轮数据源升级

1. 优先官网、校招，再补充平台/公共部门；新增亚马逊、苹果、西门子、SAP、博世及高校就业网公开入口。新增入口仅表示允许检索，实际读取能力由健康状态显示。
2. 对腾讯、字节跳动支持的公开内嵌 JSON 结构增加专用适配，必须和当前岗位 ID 完全对应；原有 JobPosting、文本及香港公务员解析保留。不调用猜测的私有接口。
3. 浏览器渲染默认在 GitHub 定时任务开启，每轮最多 4 次。只用于公开企业/校招页，HTTP 访问失败和明确验证码不进入渲染。只允许同源、公开地址、robots 允许的 GET 文本资源；不带用户 Cookie、不登录、不解决验证码。依赖跨域资源或私有 POST 的站点仍可能无法读取。
4. 来源健康记录持久化到公开岗位索引。连续 3 次访问限制/robots/网络失败后暂缓 48 小时，之后允许复查；单个缺字段或已移除岗位不触发整站暂停。成功读取清除连续失败。健康统计表示详情读取，不表示最终岗位一定符合个人要求。
5. 每日简报新增“粘贴岗位正文进行分析”。必须输入雇主、标题、地点和含职责/要求的正文；可选原链接。不猜测薪资等未披露字段。最多本机保存 50 个，可删除。手动岗位不自动提升为优先投递，仍需打开原公告核实。

## 发布检查

```sh
npm ci
npm test
npx playwright install chromium
npm run test:ui
npm run build
```

GitHub 网站构建会执行单元测试和手机/电脑浏览器回归，失败则不发布该构建。daily/enrich 在执行前检查单元测试，并串行安全保存索引，不强推。未修改评分公式、通知渠道及个人数据存储位置。

## 已知边界

仍为个人偏好生成共享搜索池的 MVP；本机档案单独评分。没有多用户独立后端、云端账户同步或后台手机推送。浏览器渲染不能保证所有招聘平台可访问。需要授权接口的平台，必须先由管理员开通并配置凭据，不能把官网入口数量当作已接通的接口数量。
